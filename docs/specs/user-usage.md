# 用户用量规格

## 统计口径

- 活跃用户指所选统计窗口内有用量记录、且符合既有用户筛选条件的去重用户。
  - 管理员、内部监控与探活用户继续排除。
  - 总人数、汇总指标和用户列表使用同一完整集合，不能以榜单前若干名代替全量。
  - 用量、余额与充值单位遵循 [金额展示规格](monetary-units.md)。
- 正式运行面通过既有排队 broker 聚合读取，不新增业务数据库直连。
  - 一次读取同时取得用量、余额、当日充值和完整活跃用户集合。
  - 数据源条数与单页展示条数不得截断全量统计。

## 展示与交互

- 指标区展示精确的活跃用户总人数。
- 用户列表支持上一页、下一页和页码摘要，可查看第 20 名之后的全部用户。
  - 每页人数沿用 `ranking.displayLimit`，该字段只表示分页大小。
  - 名次跨页连续，用量相同时按用户 ID 保持稳定顺序。
  - 翻页复用当前完整快照，不重新查库，不改变顶部汇总。
  - 刷新保留当前有效页；人数减少时收敛到最后一页，统计窗口改变时回到第一页。
  - 空列表与单页禁用无效翻页操作，刷新失败保留上一份成功数据。
- 分页沿用全站表格工具栏样式，手机端按钮与页码完整可见。
- 宽屏表格铺满可用宽度，金额与计数列按比例分配，不限制为窄表。
  - 手机按内容收紧名次、金额和计数列，减少不必要的横向滑动。
  - 邮箱列可收缩并用省略号截断，完整原文保留在单元格和悬停提示中。
  - 手机默认横向位置可直接看到标准用量与余额，其他列在表格容器内横向滚动。
  - 金额保留既有精度与单位，不截断金额来迁就邮箱。

## 验收

- 超过 100 人的集合仍完整计数，21 人、整页、末页、空集合均可正确浏览。
- 管理员及既有排除用户不进入人数、汇总或分页。
- 正式入口核对桌面和手机首屏活跃人数、第二页连续名次与页码摘要。
- 正式入口核对长邮箱省略号、紧凑行列、金额完整显示和容器滚动边界。
