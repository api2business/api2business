# 账号评分规格

- 本文件只定义评分边界；公式、样本分类、TTFT、冷却联动和优先级计划唯一见
  [上游与调度](../../skills/api2business/references/upstream-scheduling.md)。
- 账号质量分、池级综合分和优先级排序分是三个独立结果；报告必须说明作用域、样本时间窗、
  探活是否纳入以及滚动或即时口径。
- 账号级评分可以使用该账号的专用探活样本；池级综合质量排除内部 monitor 和
  `api2business-probe-*` 探活流量。两层结果不能互相替代。
- 客户自己的余额不足属于 `customer-billing`，不能降低账号质量、切号失败率、TTFT 或池级
  综合分；没有账号归属的客户错误也不能扣到任一账号。
- 成本缺失、余额失败保留和共享钱包投影分别由上述调度参考与
  [额度监控](../../skills/api2business/references/quota-monitoring.md) 定义；本规格不复制
  第二套缺失数据或缓存状态机。
- 自动优先级调度按作用域功能开关独立运行，计划生成、写入和回读分开验收。
